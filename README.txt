# WASL PWA

## الملفات
- `index.html`: نسخة موقع WASL مع إضافات PWA.
- `manifest.json`: اسم التطبيق، العرض المستقل، والأيقونات.
- `sw.js`: Service Worker لتثبيت التطبيق وFallback أساسي عند انقطاع الاتصال.
- `icons/`: أيقونات PNG بقياسي 192 و512.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى نفس مجلد النشر الذي يحتوي `index.html` في مستودع GitHub Pages.
2. تأكد أن الرابط يعمل على HTTPS.
3. افتح الرابط في Chrome على Android، ثم اختر تثبيت التطبيق/إضافة إلى الشاشة الرئيسية.
4. بعد النشر، اختبر تسجيل الدخول والرسائل ورفع الصور والصوت والمكالمات.

## ملاحظات مهمة
- الإشعارات: الزر يطلب إذن المتصفح فقط. الإشعارات الفعلية عند إغلاق الموقع تتطلب Push API وService Worker handler واشتراك Push وخادم إرسال.
- الكاميرا/الملفات: عناصر رفع الملفات الموجودة بالموقع محفوظة. الكاميرا والميكروفون يحتاجان HTTPS وإذن المستخدم.
- Offline: لا يعمل الموقع كاملًا دون اتصال؛ قاعدة البيانات والمصادقة وRealtime تتطلب اتصالًا.
- لم يتم تغيير إعدادات Supabase أو مخطط قاعدة البيانات.
