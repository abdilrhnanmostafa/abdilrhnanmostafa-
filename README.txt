WASL PWA — حزمة التثبيت

مهم: هذه الحزمة مصححة لتطابق بنية مستودع GitHub الظاهرة في الصورة، حيث تكون ملفات الأيقونات في جذر المستودع بجوار index.html وmanifest.json.

الملفات التي ترفعها إلى جذر مستودع GitHub (main):
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

يمكنك رفع README.txt أيضًا. لا تحتاج إلى مجلد icons لهذه النسخة.

الخطوات من الهاتف:
1) افتح المستودع على GitHub.
2) ارفع/استبدل الملفات الخمسة أعلاه في جذر المستودع، ووافق على Commit changes.
3) تأكد أن GitHub Pages مفعّل من Settings > Pages ويُنشر من الفرع والمجلد الصحيحين.
4) افتح رابط GitHub Pages المنشور، وليس github.com، في Chrome.
5) حدّث الصفحة. إذا لم يتغير شيء، امسح بيانات الموقع المؤقتة من إعدادات Chrome ثم افتحه مجددًا.

ملاحظات:
- هذه الحزمة لا تعدّل المستودع البعيد تلقائيًا؛ يلزم رفع الملفات إلى GitHub يدويًا.
- تم الحفاظ على إعدادات Supabase الموجودة في index.html؛ لم يتم تغيير قاعدة البيانات.
- إشعارات الخلفية الحقيقية تحتاج خدمة Push وخادمًا، وطلب إذن الإشعارات وحده لا يرسل إشعارات.
- Service Worker يوفر أساسًا بسيطًا للتعامل مع انقطاع الاتصال، وليس دعمًا كاملًا للعمل دون إنترنت.
- بعد النشر اختبر تسجيل الدخول والرسائل ورفع الصور والكاميرا.
